Utilisateur cible :
Exploitant viticole en Provence gérant plusieurs parcelles et dépendant fortement des conditions météo pour ses décisions quotidiennes.

Décisions métier :
- Déclencher ou non l’irrigation
- Activer les dispositifs anti-gel
- Planifier les traitements phytosanitaires
- Anticiper les risques climatiques (gel, sécheresse, pluie)

Approche technique :
Le système combine :
- du batch pour l’analyse historique
- du streaming pour les alertes en temps réel

Le streaming est essentiel pour les événements critiques comme le gel.

Risques d’échec :
- Données météo peu fiables
- Latence trop élevée
- Mauvaise compréhension métier
- Pipeline instable
- Interface peu exploitable
